# AutoKeeper Design System v1.0

**Last Updated:** October 26, 2025  
**Platform:** React Native (Expo)  
**Target Devices:** Mobile-first (iOS & Android)

---

## 📖 Overview

AutoKeeper uses a **modern, dark automotive theme** inspired by electric vehicle dashboards and premium car interfaces. The design emphasizes clarity, sophistication, and trust while maintaining a tech-forward aesthetic.

### Design Philosophy

1. **Dark First** — Reduces eye strain, premium feel, automotive aesthetic
2. **Cyan Accents** — Modern EV-inspired color (calm, tech-forward, not aggressive)
3. **Glassmorphism** — Subtle backdrop blur for depth and premium feel
4. **Carbon Fiber Texture** — Subtle automotive reference in backgrounds
5. **Smooth Animations** — Micro-interactions that feel responsive and polished

### Brand Personality

- 🎯 **Professional** yet approachable
- 🚗 **Automotive** without being aggressive
- ⚡ **Modern** and tech-forward
- 🛡️ **Trustworthy** for sensitive vehicle data
- 🇧🇷 **Brazilian** — Portuguese-first, local context

## 🎨 Quick Reference

### Primary Colors
- **Primary Cyan:** `#06b6d4`
- **Primary Blue:** `#3b82f6`
- **Background Dark:** `#0a0a0a`

### Typography
- **Font Family:** System Default (San Francisco/Roboto)
- **Base Size:** 16px
- **Scale:** 1.25 (Major Third)

### Spacing
- **Base Unit:** 4px
- **Scale:** 4, 8, 12, 16, 20, 24, 32, 40, 48, 64

### Border Radius
- **Small:** 12px (inputs, chips)
- **Medium:** 16px (buttons)
- **Large:** 20px (logo)
- **XLarge:** 32px (cards)

## ✅ Design Checklist

Before considering a screen "complete," verify:

- [ ] Uses colors from the approved palette
- [ ] Typography follows the scale and hierarchy
- [ ] Spacing uses the 4px-based scale
- [ ] Components match specifications
- [ ] Shadows/glows applied correctly
- [ ] Mobile-first (390px width optimized)
- [ ] Accessible contrast ratios (WCAG AA minimum)
- [ ] Portuguese copy reviewed
- [ ] Empty states designed
- [ ] Loading states considered
- [ ] Error states designed
